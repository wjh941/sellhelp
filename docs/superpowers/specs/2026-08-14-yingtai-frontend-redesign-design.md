# 盈泰副食经营管理系统前端重构设计

## 目标与边界

将现有 Vue 3 + Vite + Element Plus 前端重构为适合副食档口老板和仓管文员的高密度 B 端操作系统。系统主任务是入库、销售开单、库存风险处理、客户欠款跟进和经营复盘。

本次只改 `frontend/`。FastAPI 接口、SQLite 数据库、字段、业务逻辑、现有 API 路由以及 `.env` 全部保持不变。前端只调用已有 API；没有对应 API 的展示不伪造数据。草稿、表格布局和聊天历史仅可写入浏览器 localStorage。

## 设计方向

采用“高密度运营台”。侧栏保持稳定，表格用于连续数据比较，卡片只用于指标、风险、明确的操作分组和预览面板。设计服务于扫描和连续录入，而不是营销展示。

- Visitor mode: Operate。
- 视觉变化：3/10。保持熟悉的业务软件结构，使用明确的层级和状态，而非实验性排版。
- 动效：2/10。只使用短 hover、active、展开和加载反馈；支持 `prefers-reduced-motion`。
- 信息密度：8/10。高频页面优先显示可操作数据，避免大面积无效留白。
- 使用现有 Element Plus 作为唯一组件体系，不引入第二套设计系统或新的业务依赖。

## 主题与令牌

全局主题以 CSS 语义变量实现，并将 Element Plus 变量映射到同一套令牌。`data-theme="light"` 为默认，`data-theme="dark"` 为用户可切换状态，并记忆在 localStorage。

| 语义 | 浅色值 | 用途 |
| --- | --- | --- |
| `--yt-primary` | `#165DFF` | 导航高亮、主按钮、可操作链接 |
| `--yt-warning` | `#FF7D00` | 临期、欠款、赊销、重点提示 |
| `--yt-danger` | `#F53F3F` | 过期、高风险、删除确认 |
| `--yt-success` | `#00B42A` | 库存正常、回款完成、盘盈 |
| `--yt-page` | `#F2F3F5` | 页面背景 |
| `--yt-surface` | `#FFFFFF` | 卡片和工作区表面 |

卡片半径统一为 8px，阴影只用于可提升的指标卡、预览面板和弹窗。基础字体使用系统无衬线字体栈。表格和表单正文不低于 14px，按钮文字不低于 15px，关键提交按钮使用更高的点击区域。深色主题改用对应的深层背景、表面和文字变量，不更改状态色含义。

## 全局框架

应用采用固定左侧导航栏、顶部 Header 和独立滚动的主内容区。

- 侧栏展开为 248px，折叠为 72px；图标与文字清晰可辨，折叠不使用缩小到难以点击的控件。
- 导航分组为：工作台、基础档案、入库业务、销售开单、退货盘点、行情记录、报表中心、生意顾问、系统设置。既有路由路径保持不变。
- Header 显示“盈泰副食贸易部 · 经营管理系统”、当前时间、浅色/深色切换和数据库备份按钮。备份继续调用现有 `backupDatabase` 接口。
- 页面标题、面包屑和主要操作放在同一行；筛选条和表格保持固定顺序，减少习惯迁移。

## 全局交互组件

共享组件与组合式函数只做前端表现层，包含：

- 可拖动对话框外壳：用于入库、销售和编辑弹窗；拖动只改变浏览器中的对话框位置。
- 草稿存储：入库和销售保存未提交表单到命名 localStorage 键，关闭时提示恢复或清除。提交成功后清除对应草稿。
- 表格偏好：列显隐、列宽和本地行排序保存为用户偏好。业务排序、后端筛选和数据源不被更改。
- 行信息预览：产品、客户、批次和风险行使用 tooltip 或 popover 展示已有数据；悬浮不会触发写入。
- 受控快捷编辑：只有备注、安全库存和市场行情备注可通过正式的既有更新接口保存。进价与售价不允许行内编辑。Enter 保存、Escape 取消、保存失败保留原值并显示错误。
- 可见状态：加载使用与原布局一致的骨架或表格加载态；空数据给出明确下一步；接口错误沿用现有消息提示，并在当前表单保留输入内容。

## 第一期开单与工作台

### 工作台

工作台使用已有库存、销售、客户欠款、预警和仪表盘接口展示以下真实统计：今日销售额、本周销售额、总应收欠款、库存占用资金。未由 API 提供的统计拆分不显示为精确数字。

下方按任务分成四个可折叠风险区：临期商品、库存不足、逾期欠款、热销或滞销概览。每个风险项目同时有颜色和文字徽章，并提供到库存、客户、入库或销售页面的明确跳转。老板可“暂时忽略”单个项目，状态只保存在浏览器并可恢复。ECharts 只渲染已有指标，悬浮提示展示原始数值。

### 销售开单

销售页保留订单列表和既有创建 API，但创建体验改为稳定三栏：

1. 左栏为客户搜索、客户类型、价格档位、当前欠款和额度预警。
2. 中栏为商品联想搜索及库存信息。选择商品后按当前客户价格档位带出既有售价并加入订单。
3. 右栏为可拖动排序的订单预览。数量可直接编辑，小计、总额和利润即时重算；单行可删除。

赊销、现结和部分结算仍提交原有 `payment_type` 与 `paid_amount` 字段。客户接近额度时显示橙色风险标签和明确文字，不使用无提示动画。送货单预览为当前订单的只读前端视图，打印使用浏览器打印样式；现有导出接口按原有格式保留。F5 新建、Escape 清空订单都应在页面内拦截并展示明确反馈。

### 入库开单

入库列表保留原表格与删除、详情操作。新建入库单升级为可拖动的宽屏双栏弹窗：左侧保存供应商、操作员和商品搜索，右侧显示入库明细、批次、生产日期、到期日、数量、进价和总额。选中商品后立即在右侧新增明细；数量与进价实时重算；行悬浮显示删除按钮。到期日存在时，显示“保质期剩余 N 天”的状态提示。提交字段仍为既有 `PurchaseOrderCreate` 结构。

## 第二期档案、库存与经营页

### 基础档案

商品、客户和供应商列表支持表格与卡片视图切换。商品表格清晰展示三档售价和安全库存，客户“晨升膳食”在名称匹配且当前数据存在时显示 VIP 徽章，其他 VIP 客户沿用已有 `is_vip` 字段。商品编辑表单拆为基础信息、价格体系和库存安全三组；安全库存输入时前端显示当前库存差值。

### 退货、库存与盘点

库存表格固定表头、横向滚动、斑马行和批次日期风险着色。退货选择产品后展示已有库存和可退数量，前端即时验证数量。盘点录入显示差额，盘亏使用红色文字与状态，盘盈使用绿色文字与状态，确认仍调用现有盘点接口。

### 行情、定价与报表

市场行情使用按日期倒序的时间线卡片和本地时间范围筛选，原网络行情待确认流程不变。定价参考将采购进价、历史区间、人工行情和三档参考价分组，模拟滑块只改变预览中的毛利与毛利率，并明确标注不会写入真实售价。周报以报告式排版展示已有排行、风险清单和图表，点击图表仅做本地筛选；导出和打印只使用现有接口或浏览器打印能力。

## 第三期顾问、设置与横向体验

生意顾问保留现有会话 API，升级为左侧快捷问题、右侧对话主区。回答使用安全的 Markdown 子集渲染，复制、点赞和点踩仅保存本地状态，历史会话本地镜像不写入新的后端数据。加载状态使用简洁的逐字提示，不使用持续动画。

设置页把数据库备份、恢复和现有外部行情同步状态分成清晰操作卡。API Key 区域只能说明服务端配置状态和环境变量位置，禁止在浏览器录入、保存或暴露密钥。主题切换也在该页提供并与 Header 同步。

## 风险、性能与验收

- 所有高风险状态同时使用颜色、文字与徽章。
- 所有破坏性动作继续经过确认弹窗；草稿恢复和清除均有明确反馈。
- 不使用重动画、粒子、渐变光球、装饰性 SVG 或新的图形库。
- 支持 100% 和 125% Windows 缩放，宽表格使用横向滚动而非压缩字段。
- 保持现有 `.env` 和 API 客户端；不修改 `backend/` 中任何文件。
- 首期验收包含浅色/深色主题、桌面与窄窗口布局、创建销售单、创建入库单、草稿恢复、快捷键、风险跳转和浏览器打印预览。
